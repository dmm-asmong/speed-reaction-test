# 스피드 반응속도 테스트

색상 변화에 맞춰 클릭하고 반응속도를 밀리초(ms) 단위로 측정하는 간단한 웹 게임입니다.

## 게임 방법

1. 파란색 상자의 **클릭해서 시작**을 누릅니다.
2. 빨간색 **기다리세요...** 화면에서는 클릭하지 않습니다.
3. 2~4초 뒤 초록색 **지금 클릭하세요!** 화면이 나타나면 최대한 빠르게 클릭합니다.
4. 최근 기록과 최고 기록을 확인하고 다시 도전합니다.

빨간색 화면에서 미리 클릭하면 **부정 출발!**로 처리됩니다.

## 실행 방법

별도 설치나 빌드 없이 [`index.html`](./index.html)을 웹 브라우저로 열면 바로 실행됩니다.

## 주요 기능

- 2~4초 사이의 무작위 대기 시간
- `performance.now()`를 이용한 반응시간 측정
- 최근 기록 및 최고 기록 표시
- 브라우저 `localStorage`에 최고 기록 저장
- 모바일 화면과 키보드 조작 지원
- 사용자 모션 감소 설정 지원

## 구성

HTML, CSS, JavaScript가 모두 `index.html` 한 파일에 포함되어 있습니다.
